💵 Выручка и чистая прибыль по салонам (1С)

Выручка из 1С (sales_daily_1c, net_sales) минус постоянные затраты салона (раздел Расходы → Постоянные затраты). Чистая прибыль = выручка − постоянные затраты. Общие затраты распределяются по салонам пропорционально выручке. Период можно задать выбором месяца или произвольным диапазоном дней; для неполного месяца постоянные затраты берутся пропорционально количеству дней. Обновляется автоматически.

📅 Чистая прибыль за вчера по салонам

Данные из подраздела Продажи → Ежедневные продажи. Расчёт не зависит от продаж из Excel.

💼 Зарплата от продаж (2%)

Зарплата считается как 2% от выручки сотрудника за выбранный период (выручка из 1С, employee_sales_1c, без учёта возвратов). Если сотрудник сопоставлен с записью в справочнике сотрудников — используется его индивидуальный процент. Кнопка «Выплатить» фиксирует выплату в журнале и добавляет её в затраты (категория «Зарплата»), поэтому выплата отражается в чистой прибыли на главной странице. Повторная выплата за тот же период блокируется.

📐 Размер этикетки

Последние документы «Поступление товаров» из 1С. Если у позиции уникальных штрихкодов меньше, чем пришло пар — она подсвечивается: нужно сгенерировать и распечатать этикетки через вкладку «Печать».

Последние документы «Перемещение товаров» из 1С: откуда → куда, размеры и для каждого размера — конкретные штрихкоды, которые реально переехали. Так видно, куда ушёл каждый конкретный товар.

Сканируйте штрихкоды экземпляров сканером (курсор в поле ниже). Затем нажмите «Сверить», чтобы сравнить отсканированное с тем, что числится на складе.

🧾 Распечатать ценник для витрины

Выберите склад и товар. Отметьте один или все размеры, для каждого укажите количество этикеток и выберите конкретный штрихкод или «все коды» — затем печать.
